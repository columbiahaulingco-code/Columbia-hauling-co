## Deploy with GitHub Pages

1. Go to **Settings** in this repository.
2. Click **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch: `main`.
5. Choose folder: `/root`.
6. Click **Save**.

Your site should publish at:

`https://columbiahaulingco-code.github.io/Columbia-hauling-co/`

If you connect a custom domain later, point the domain to GitHub Pages or use Vercel for easier domain setup.
